# ビー玉コースのたきの機構

距離はメートル、角度はラジアン。物理は `physics.js` が1/480秒ずつ進める。描画側は部品の位置・姿勢・材質と発音を状態から組み立てる。`window.__GAME__.step(dt)` の引数は秒。`getState()` は独立したスナップショットを返す。

| 部品と更新箇所 | 動くきっかけ・接触 | 止まり方と余韻 |
|---|---|---|
| ばね `lever.q, lever.v` ／ `tick, release` | 指の荷重で200 N/mのばねを最大40 mm圧縮する。離した瞬間の弾性エネルギーの1.2%を押し子から玉へ伝え、短いタップには予圧分も加える。 | ばねは質量と粘性抵抗に従って伸び、ストッパーで止まる。射出中は押し子が掛からない。 |
| ビー玉 `balls[].x, y, vx, vy, rotation` ／ `falling, collide, roll` | 半径8 mm、質量5.36 gの球。重力9.80665 m/s²の斜面方向成分に、中実球の転がり慣性を含む係数5/7を掛ける。釘の法線方向の相対速度に反発係数0.55を適用する。 | 接触が離れると重力で次の釘に向かう。回転は移動方向と接触摩擦で更新し、着地後も残った角速度が減衰する。 |
| 釘 `pins[].q, v` ／ `collide, machinery` | 当たった釘だけが横向きの反力を受ける。画面上で釘を直接触れた場合は小さな外力が加わる。 | 根元の弾性と減衰で戻る。位置と速度の絶対値の和が微小になると更新を休む。 |
| 受け皿 `balls[].cup, cups[].lip` ／ `falling, funnel, settle` | 各皿は1個で満杯。最後の釘を離れた位置と空いている入口によって進路が決まる。下段は溝の勾配と抵抗を近似し、埋まった入口の木片が傾く。 | 玉が皿の中央で減速して着座すると爪が掛かる。観覧車に渡した皿の木片はばねで戻る。 |
| 風車と鐘 `cups[].omega, wing, bell` ／ `settle, machinery` | 玉の着座がその皿の羽根に回転力を与え、鐘を打つ。鐘はWeb Audioの減衰する部分音で鳴る。 | 羽根は軸の粘性と摩擦で止まる。鐘の振り子には打撃の余韻と微弱な風圧が残る。 |
| 箱とオルゴール `lid.q, wheel.work, wheel.angle` ／ `machinery` と `play.js` の `sound` | 3皿の着座で箱の留め金が外れる。蓋はばねで開き、歯車の角度が次の歯を通るたびに櫛歯の音が鳴る。 | 荷下ろし後は蓋が減衰しながら閉じ、次の玉が送り溝を下る。 |
| 観覧車とかご `wheel.goal, wheel.v, baskets[].q, balls[].path` ／ `machinery, pathStep` | 空いたかごが上で止まると、着座順に玉がレールを下る。玉が乗ると送り機構が次のかごへ進む。回転力には載った玉の重力モーメントも加わる。 | 送り位置では留め金が効く。各かごの荷重・角度・車輪の加速度に応じて別々に揺れる。3個乗った後はもう1周して箱に戻す。 |
| 布・影・埃 `cloth[].q, dust[]` ／ `environment` | 9区画の布に別々の風圧・張力・隣接区画の力が掛かる。裾の変位が床の光の境目に伝わる。28粒の埃は局所的な空気の流れを受ける。 | 風が弱まると布は弾性で戻る。埃は抵抗で減速し、次の風で再び動く。粒の入れ替えや座標の巻き戻しは行わない。 |
| 指のお手本 `guide.q, reach, stage` ／ `environment` | 発射可能な状態で約4秒待つと、木の指がレバーに近づく。押す・離すの切り替えは実際の到達位置で決まる。 | 指を触れた時点でお手本は退き、次の発射が可能になってから待ち時間を数え直す。 |

## 状態テスト

`node games/d-07/test/state.test.cjs` で再実行できる。無操作10秒、同一初期状態から圧縮量だけを10 mmと40 mmに変えた比較、接触速度の単体検査、入力から自動復帰までの連続2周を検査する。

0.05秒ごとの全状態は `test/trace.jsonl.gz`、隣接差・区画間の比較・1/480秒ごとの最大移動量は `test/measurements.json` に記録する。玉は個体IDを追跡して比較し、箱から新しく出る玉と収納済みの玉を別の個体として扱う。
