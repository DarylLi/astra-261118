# 港の動きと状態テスト

状態更新の単位は m、s、rad、kg。physics.js の step(dt) は受け取った秒数を 0.01 s ずつ積分し、端数を次回に繰り越す。harbor.js は計算済みの位置、姿勢、波面、照明を読み取る。画面上に文字は表示しない。

| 対象 | 状態変数と更新箇所 | 動く原因、接触、停止後の余韻 |
|---|---|---|
| クレーンと荷 | hook.vx/vz、ax/az、wx/wz、updateHook | 指の目標位置と現在位置の差で台車を加速する。荷重で加速限界が変わる。支持点が加速すると荷が遅れ、重力が振り戻す。自由振動の減衰率は 0.4 /s。空き枠へ位置を合わせる間は制動を強める。 |
| 巻き胴とロック | hook.y/vy/spool/lock/lockV、updateHook と workflow | 巻き出した距離で胴を回す。荷の上面または甲板で下降を止める。ロックはばねと摩擦で行き過ぎてから収まる。ロック後に荷重を引き受け、着床時に船へ渡す。 |
| 搬送台 | sleds[].z/speed、updateCargo | 荷が持ち上がると倉庫に戻り、次の荷を搬出する。区画ごとの上限速度、加速、残りの距離で止まる。 |
| 船体 | ships[].displacementKg/heave/roll/trim、updateShips | 荷の質量を排水体積に換算し、船体を浮力と減衰で支える。着床が上下・横揺れの速度に衝撃を与える。前後・左右の波高差に追従し、停泊中にも小さく動く。 |
| 船の入れ替え | ships[].x/speed/mode、workflow と updateShips | 3個目のロックを外しフックを巻き上げると汽笛。出港船が加速し、待機船が進入する。岸までの距離で減速し、荷がそろうと操作を再開する。 |
| 波と白波 | water.h/v/foam、updateWater | 1,375格子の近傍水位差、局所風圧、着床、船首の押し波、船尾の引き波で水が動く。岸壁で反射し、外側で減衰する。白波は各格子の水の速度に応じて生じ、運動が弱まると消える。 |
| 防舷材 | fenders[].angle/v、updateWater | 19個がそれぞれの取り付け位置の波を受け、吊り下げ部の復元力と摩擦で揺れ戻る。 |
| 空・光・浮遊粒子 | winds[].u/v/light、motes[].x/y/vx/vy、updateAir | 9区画で突風の到着と強さが異なる。雲の明るさは風に遅れて変わる。35粒の浮遊粒子は局所風と空気抵抗を受け、突風が過ぎても速度が残る。 |
| 操作のお手本 | idle/hintActive、tick と live、表示は guideHand | 荷を選べる時と船に置ける時だけ、無操作4秒でフックから対象まで指が移動する。対象に触れると消える。 |
| 音 | events[].type/power、workflow と sound.update | ロック、着床、汽笛は接触または工程の切り替わりで1回ずつ発音する。着床では打撃の強さに応じて複数の周波数が励起され、それぞれの速さで減衰する。 |

## 記録

リポジトリのルートで `node games/d-08/tests/state.cjs` を実行すると、同じ種で記録を再生成できる。

- `state-trace.ndjson.gz` は0.05秒ごとの記録。船、荷、フック、搬送台、風、防舷材、浮遊粒子と、水面の12観測点を収録する。
- `measurements.json` の差分計算では水面の全1,375格子を使用する。船と荷は物体IDで追跡し、入港した船と出港した船を同一物体として差し引かない。
- 無操作10秒、積み込みから次船の準備完了まで、同一入力でロープ長12 mと6 mを比較する4系列。沈み込みは下降開始から着床後2.30秒までの差で、局所の波と船体の余韻を含む。
- 各系列で隣接刻みを比較する。水位、白波、防舷材、浮遊粒子、風と明るさについて、全区画が一律に動く刻みを検査する。

指定2サイズの初期配置は透視投影の座標で確認。実際の画面、HSV彩度中央値、ブルームの見え方は描画未確認。音は発音イベントを計測し、実機での聴取は未確認。
