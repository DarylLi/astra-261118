# 味噌汁を混ぜる場面の操作検証

## 実施方法と結果

Node 上で、同梱の Three.js、ゲームの HTML が指定するスクリプト、実際の Pointer Events ハンドラーを読み込んだ。透視投影、レイと水面の交差、具材、人物の姿勢、アニメーション、音の発音指示までを計算した。画面、イベント配送、Web Audio の出力先にはテスト用の代替を使用した。

| 検査 | 時間と入力 | 結果 |
| --- | --- | --- |
| 試作時の流体計算 | 実時間600.01秒。36,000ステップで接触、円運動、逆転、保持、解放 | 14回再開。解放後1秒で角速度4.40から3.33に減衰 |
| 統合後の操作 | 実時間599.90秒でゲーム内600秒。毎回おたまを画面に投影し、その座標からドラッグ | 16回再開。豆腐の持ち上げ、わかめの引き寄せ、逆転を検出 |
| 修正後の最終版 | 同じ方式でゲーム内600秒を早送り。36,000フレーム | 19回再開。具材の位置は有限かつ鍋内。溶け残りと混合率の合計の最大誤差は約1.2×10⁻¹⁶ |

最終版では、具が重なると豆腐が周囲を押すように調整した。直線往復でも少しずつ溶けるようにし、溶けた味噌を40×40の濃度格子で運ぶ処理を追加した。鍋の投影幅は縦画面で241から266 CSS ピクセル、横画面で363から422 CSS ピクセルに広げた。

## 発見ごとの条件、結果、次の試し方

半径は汁面の半径を1とする。角速度の単位は rad/s。数値は最終版の自動入力および条件をそろえた追加測定で取得した。

| 操作と条件 | 観測した変化 | 次に試せる操作 |
| --- | --- | --- |
| 同じ小さな往復を3秒間、味噌に当てる／離して行う | 対象の塊の質量減少は0.0787／0.0033。直接当てた試行では、局所濃度の閾値を超えた格子が192個になった | 残った塊を見つけて狙う。円運動に移って濁りを運ぶ |
| 同じ半径で円を速くする | 最初の低速区間末の角速度2.92から、高速区間で4.40に上昇。中心の水面が下がる | 渦が強い間に手を離し、具が来るのを待つ |
| 高速の円から指を離す | 1秒後3.33、4秒後1.44。おたまの移動が止まっても具の移流は続いた | 流れてきた具をおたまの前で拾う |
| 残った流れに逆らって回す | 正方向1.44からゼロを通り、1秒後に逆方向−2.89。具材はそれぞれの慣性で向きを変える | 減速した瞬間に円をやめて、具の間を横切る |
| 同じ半径の豆腐・わかめ・ねぎに同じ流れを当てる | 初回ステップの接線速度は順に0.0267、0.0593、0.1020。ねぎが先行し、豆腐が遅れる | ねぎを追う速さから、豆腐に合わせたゆっくりした操作へ移る |
| 豆腐の下へゆっくり入り、縁へ運んで静める | 豆腐がおたまに収まり、持ち上げ率が1.00に到達。解放後に保持が外れ、水面へ戻った | 縁の別の場所まで運ぶか、中央へ滑らせて流れに戻す |
| 縁のわかめを通って中央へ引く | わかめが後ろの流れに乗り、同じ葉の半径が最大0.626縮小。葉の開きは最大0.993 | 集めた葉の周りで円を描き、再び流す |
| 溶け残りをなくす | 成功時に湯気と笑顔の強度が連続上昇。成功音の発音指示を19回分記録。湯気が落ち着くと塊が戻った | 次の鍋では直線の往復から始めることもできる |

## 入力、表示範囲、負荷

- 390×844では上47・下34 CSS ピクセル、1180×820では下20 CSS ピクセルを余白と仮定した。人物の頭と鍋の左右が可視範囲に収まることを透視投影で確認した。両サイズとも、各人物の顔の中心へ飛ばしたレイはその人物に最初に当たった。
- 空の場所を押しても混合率とおたまの操作座標は変化しなかった。初回だけおたまが小さく動いて誘う。おたまを押すと指を捕捉し、沈みと波紋が始まる。柄の中心から18 CSS ピクセルずらした押下も受理した。
- 二本目の押下・移動・解放を挟んでも最初の指が操作を維持した。キャンセル、捕捉喪失、回転、非表示で保持を解除した。無操作3.93秒では指のお手本が非表示、4.32秒では表示となり、操作再開で消えた。
- 非表示中に模擬時計を30秒進めてもゲームの時刻は進まず、予約フレームは0件。復帰時の予約は1件で、停止時間分の早送りは発生しなかった。
- 音声の初期化は最初のタッチで1回。休止・再開、および成功時の和音の発音予約を確認した。コンテキストメニュー、ジェスチャー、タッチ移動イベントで既定動作を抑止した。
- 泡28個、縁の泡輪25個、湯気8本、接触波1本、具材42個を固定して再利用する。試行前後で場面の直下オブジェクト数と具材数は一致した。模擬フレームの遅延が続く条件で、描画倍率は1.224から0.884に下がった。
- ローカルの7スクリプトの構文と読み込み先を確認した。独自シェーダー3組は、Three.js のチャンクを展開したコンパイル検査で Mesa の OpenGL ES コンパイルとリンクに成功した。自動操作は例外なく完走した。

## 未確認

ブラウザでの描画観察、ブラウザの実行コンソール、iPhone・iPad実機での操作・音質・実フレームレート、子どもによる発見のしやすさは未確認。記載した時間、位置、音はエンジニアによる自動検査の測定値または発音指示である。

## 再実行

リポジトリのルートから次のコマンドで、最終版の早送り検証を実行できる。末尾に `--realtime` を付けると入力を実時間で進める。

```sh
node games/miso-stir-A/checks/verify.cjs
```
